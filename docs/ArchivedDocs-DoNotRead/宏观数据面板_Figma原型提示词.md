# 宏观数据面板 · Figma 原型生成提示词包

日期：2026-10-11
用途：驱动 Figma AI（Figma Make / First Draft）生成可作为 Obsidian 插件前端开发起点的 UI 原型。原型定位是**视觉基准**（布局、组件、状态、信息密度的参照），不是可直接使用的代码。

---

## 0. 使用方法

1. **工具选择**：推荐 Figma Make（可交互、可逐屏迭代）；First Draft 亦可（静态多屏）。
2. **顺序**：每次会话先粘贴 §1 全局上下文提示词，再粘贴 §3 中的一屏提示词。**一次只生成一屏**，避免 Figma 混合多屏。
3. **迭代**：生成后按 §5 检查清单核对，用追加指令修正（例："把季节对比选项改为置灰，加 tooltip 显示不可用原因"）。
4. **语言**：提示词为中文，Figma AI 可直接理解；若所用模型中文效果弱，可先要求翻译成英文再粘贴。
5. **宽度基准**：主视图按 1440px 桌面容器设计；详情页同时出 720–960px 窄版（Obsidian 标签页实际宽度）。

## 1. 全局上下文提示词（每次会话开头粘贴）

```text
我在开发一个 Obsidian 桌面应用插件：宏观经济与消费数据面板，服务于中国购物中心总经理的月度经营决策。请为我生成 UI 原型。

【产品背景】
- 用户每月查看一次中国宏观与消费数据（社零、CPI、M1/M2 等），辅助判断消费趋势与业态配比，随后撰写月度判断笔记
- 数据由本地 Python 程序加工成 JSON 文件，插件只负责展示，无任何网络请求
- 界面运行在 Obsidian 笔记软件内部，是嵌入式的数据面板视图，不是独立网站
- 整体气质：专业金融数据终端（参考 FRED、Grafana），信息密度高但克制安静；不是营销网站，不要 hero 区、不要插画、不要渐变和装饰堆砌

【设计系统】
- 深色主题为主（Obsidian 用户主流），之后我会要求出浅色变体
- 深色板：页面背景 #1e1e1e，卡片背景 #262626，描边 rgba(255,255,255,0.10)，正文 #dcddde，次要文字 #999999
- 强调色只允许一个绿色 #4ec9a5（选中态、焦点、主数据线）；语义色仅三类：新鲜度圆点（新鲜=绿 / 临期=琥珀 / 过期=灰）、待处理告警（琥珀）、需手动（红点）
- 中文用系统无衬线（苹方/微软雅黑），数值用等宽数字（tabular figures）
- 组件库：指标卡片、分段切换器（segmented control）、下拉选择器、tooltip、badge 徽标、可折叠说明条、数据表格、折线图占位区
- 间距按 4/8/12/16/20/24 栅格，圆角 8–12px，卡片有 1px 描边和内边距，无阴影堆叠

【内容要求】
- 全部使用真实感中文内容：指标名、数值、日期必须具体，我会逐屏提供数据
- 数据展示必须诚实：缺失数据显示断线或"缺失"标记，不编造平滑曲线；每条数据都标注数据期（如 2026-09）
```

## 2. 设计系统补充提示词（需要时追加）

```text
补充设计系统细节：
- 主题：请为本屏同时生成深色版与浅色版（浅色板：背景 #ffffff，卡片 #f6f6f6，描边 rgba(0,0,0,0.10)，正文 #222222，次要 #6e6e6e，强调绿 #0e8a6a）
- 图表占位区用灰色线框示意即可，无需生成真实图表数据；主数据线用强调绿，叠加序列用浅灰虚线
- 所有交互组件请给出三态：默认 / hover / 选中；不可用态单独说明
- 数字排版：当前值用 28–32px 等宽字体加粗；卡片内其余数字 14px；变化量带方向箭头（↑↓）和 pct 单位
```

### S2 单指标详情页（MVP 核心屏）

```text
生成「单指标详情页」一屏，960px 宽（Obsidian 标签页内），深色主题。

结构自上而下：
1. 页头：指标名「社会消费品零售总额 · 当月同比」（20px）；元信息行（14px 次要色）：地区 全国 · 频率 月度 · 单位 % · 数据期 2026-09 · 采集于 2026-10-15 · 绿点新鲜度
2. 可折叠解读条：「社零同比反映全国消费总量动能，与餐饮收入、网上零售增速交叉观察可判断业态结构。」
3. 工具栏（一行，自动换行）：
   - 模式分段器：日历序列（选中）/ 季节对比 / 同比序列
   - 图型分段器：折线（选中）/ 柱状 / 面积 / 表格
   - 变换分段器：原值（选中）/ 同比
   - 范围分段器：1年 / 3年（选中）/ 5年
   - 叠加下拉：「+ 添加对比指标」，已选项显示为可移除 chip：「居民可支配收入同比 ×」
4. 主图（高约 320px）：60 个月折线，2021-10 至 2026-09；主实线用强调绿；叠加序列（可支配收入同比）浅灰虚线，与主线同一 Y 轴（单位一致才允许叠加）；图中两处断线示例：2022-04 与 2025-02 数据缺失，折线中断不跨接，断点处小标记「缺失」；Y 轴范围 -5 到 15
5. 图表下方注释条（浅琥珀底）：「注：1–2 月为春节错位期，图中已合并显示（两月均值），同比解读需注意口径。」
6. 底部数据表：最新 12 期，三列：月份 / 数值（%）/ 修订版本；其中 2026-08 一行版本标「v2」，体现数据修订追加新版本；表格上方小字说明「呈现层始终取最新版本」
```

### S3 不可用状态与原因提示（capabilities 规则的视觉表达）

## 5. 生成后检查清单

对照本产品规则逐项核对，不满足则用追加指令修正：

- [ ] 置灰项均有可见的不可用原因（tooltip 或行内标注），无静默禁用
- [ ] 缺失数据真实断线，未用零值或平滑曲线跨接
- [ ] 春节合并显示处有文字说明条
- [ ] 每条数据同时标注数据期与新鲜度圆点
- [ ] 手动录入的数据带「手动」徽标
- [ ] 叠加序列与主线同轴（单 Y 轴），单位不一致的叠加项被置灰
- [ ] 深浅双主题均已生成，色彩语义一致
- [ ] 无移动端布局假设（底部 tab、手势提示等）
- [ ] 组件可映射为 HTML/CSS：auto layout、标准矩形卡片、无装饰性插画与渐变

## 6. 边界说明（给后续开发者）

- Figma 原型是**视觉基准**，不直接产出 Obsidian 代码；实现时以 Obsidian 主题变量（`--background-primary`、`--text-normal` 等）对齐色彩，而非硬编码 Figma 色值。
- 图表最终用 ECharts 渲染（折线/柱状/面积/表格），Figma 中的图表区为占位示意。
- 视图状态模型与置灰规则以 [宏观数据面板_对话总结与定稿_v0.1.md](宏观数据面板_对话总结与定稿_v0.1.md) §3.4/§5 为准；本提示词包中的文案与 reason_code 均引自该基线。
